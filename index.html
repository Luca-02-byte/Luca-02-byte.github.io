Projects

Bayesian Credit Risk

Bayesian variable selection (SSVS, spike-and-slab priors) for loan default prediction, implemented in NIMBLE (R). Identifies the strongest predictors of default via posterior inclusion probabilities, and uses posterior predictive distributions to compare default risk across borrower profiles.

Machine Learning in R via tidymodels

Supervised and unsupervised learning on real datasets: regression (Boston housing), classification and clustering (penguins). Compares linear and non-linear models, trees, ensembles, KNN, K-means and PCA, with hyperparameters tuned on a validation set and a held-out test set.

Empirical Asset Pricing on the UK Stock Market

Time-series and cross-sectional tests of the CAPM, Fama-French and Carhart models on ten UK size sorted portfolios (1980–2010), with GRS tests and second-stage cross-sectional regressions.
